# Fonts

Bundled caption fonts, all under the SIL Open Font License (see `OFL-*.txt`):

| Font | Used for |
|---|---|
| Montserrat ExtraBold / Black | default captions and titles |
| Anton | `--font Anton`, condensed bold look |
| Noto Sans Devanagari Bold / ExtraBold | picked automatically for Hindi (Devanagari) text |

Drop any other `.ttf`/`.otf` here and use it with `--font "Family Name"`.
